## 🎯 项目背景

### 项目概述

**Nexlyn 融合管理平台** 是一个为 LynxGraph 逻辑引擎提供的可视化管理平台，采用前后端分离架构，旨在打造统一的视频监控、物联网、算法管理和逻辑引擎融合平台。

### 核心功能模块

1. **视频管理**：设备接入、分屏监控、媒体管理、录像管理
2. **算法管理**：云边端 AI 算法统一管理平台
3. **物联管理**：物联网设备全生命周期管理
4. **事件管理**：基于 Skylark 的事件查询和统计分析
5. **逻辑引擎**：基于 LynxGraph 的可视化规则引擎
6. **系统管理**：用户权限、租户管理、组织架构等

### 技术架构

- **后端**：Go 1.25.1 + go-zero + PostgreSQL + Redis + Etcd
- **前端**：React 18 + TypeScript + Ant Design Pro + UmiJS
- **中间件**：MQTT + MongoDB + ClickHouse
- **媒体**：m7s.live v5 + GB28181
