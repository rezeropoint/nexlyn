# 前端编码规范 v2

> 基于 **Ant Design 5.29.1** + **ProComponents 2.8.10** + **React 18**
> 为 Ant Design 6.0 迁移做准备

---

## 核心原则

1. **统一使用 Ant Design 体系** - 禁止原生 HTML 元素，优先 ProComponents
2. **纯 CSS 变量优先** - Less 文件用 `var(--ant-*)`, TSX 用 `theme.useToken()`
3. **禁止硬编码颜色** - 不允许 `#fff`、`rgb()` 等
4. **不修改 ProComponents 样式** - 让组件自动适配主题
5. **避免 v4 废弃 API** - 为 v6 迁移做准备
6. **React 18+ 写法** - 使用 hooks、函数组件

---

## 组件使用规范

### 禁止使用原生 HTML 元素

所有 UI 组件必须使用 Ant Design 或 ProComponents，确保主题一致性和样式统一。

| 原生 HTML | ❌ 禁止 | ✅ 使用 |
|-----------|--------|--------|
| `<button>` | 原生按钮 | `<Button>` |
| `<input>` | 原生输入框 | `<Input>` / `<ProFormText>` |
| `<select>` | 原生下拉 | `<Select>` / `<ProFormSelect>` |
| `<table>` | 原生表格 | `<Table>` / `<ProTable>` |
| `<form>` | 原生表单 | `<Form>` / `<ProForm>` |
| `<a>` | 原生链接（样式目的） | `<Button type="link">` / `<Typography.Link>` |
| `<img>` | 原生图片 | `<Image>` |
| `<ul>/<ol>` | 原生列表 | `<List>` |
| `<textarea>` | 原生多行输入 | `<Input.TextArea>` / `<ProFormTextArea>` |
| `<checkbox>` | 原生复选框 | `<Checkbox>` / `<ProFormCheckbox>` |
| `<radio>` | 原生单选框 | `<Radio>` / `<ProFormRadio>` |
| `<div>` 容器布局 | 手写 flex/grid | `<Flex>` / `<Space>` / `<Row>/<Col>` |
| `<div>` 卡片容器 | 手写样式 | `<Card>` / `<ProCard>` |

### 优先级：ProComponents > Ant Design > 原生

```tsx
// ❌ 禁止：原生 HTML
<button onClick={handleClick}>提交</button>
<input type="text" value={name} onChange={e => setName(e.target.value)} />
<table><tr><td>数据</td></tr></table>

// ⚠️ 可用：Ant Design 基础组件
<Button onClick={handleClick}>提交</Button>
<Input value={name} onChange={e => setName(e.target.value)} />
<Table columns={columns} dataSource={data} />

// ✅ 推荐：ProComponents（功能更强）
<ProFormText name="name" label="名称" />
<ProTable columns={columns} request={fetchData} />
```

### 例外情况

以下场景允许使用原生 HTML：

1. **语义化结构元素**：`<header>`、`<main>`、`<section>`、`<article>`（页面结构）
2. **纯布局容器**：`<div>` 用于简单包裹（无样式目的时可用）
3. **文本段落**：`<p>`、`<span>`、`<h1>`~`<h6>`（纯文本内容）
4. **第三方库要求**：如 X6 图编辑器的 DOM 挂载点

## 样式规范

### 静态样式：Less + CSS 变量

适用于：固定颜色的图标、文本、背景、边框

```tsx
// ❌ 禁止：静态颜色用 token
<WifiOutlined style={{ color: token.colorSuccess }} />
<Paragraph style={{ color: token.colorTextSecondary }}>描述</Paragraph>

// ✅ 正确：使用全局主题类（src/styles/theme.less）
<WifiOutlined className="icon-success" />
<Paragraph className="text-secondary">描述</Paragraph>

// ✅ 正确：使用组件 Less 类
<Paragraph className={styles.description}>描述</Paragraph>
```

```less
// Component.less
.description {
  color: var(--ant-color-text-secondary);
}
```

**全局主题类**（`src/styles/theme.less`）：

| 类型 | 类名 |
|------|------|
| 图标 | `.icon-primary` `.icon-success` `.icon-warning` `.icon-error` `.icon-info` |
| 文本 | `.text-primary` `.text-secondary` `.text-tertiary` |
| 背景 | `.bg-primary` `.bg-primary-bg` `.bg-success-bg` |

### 动态样式：useToken

适用于：条件判断颜色、数据驱动颜色、渐变背景、第三方库

```tsx
import { theme } from 'antd';

const Component: React.FC = () => {
  const { token } = theme.useToken();

  // ✅ 条件判断颜色
  const getColor = (status: string) => {
    const map = { success: token.colorSuccess, error: token.colorError };
    return map[status] ?? token.colorTextSecondary;
  };

  // ✅ 渐变背景（需要组合多个颜色值）
  const gradient = `linear-gradient(135deg, ${token.colorPrimary}, ${token.colorPrimaryActive})`;

  // ✅ 数据驱动颜色
  const items = data.map(item => ({ ...item, color: token[item.colorKey] }));

  return <div style={{ background: gradient, color: getColor(status) }} />;
};
```

**何时保留 useToken**：
- 渐变背景、动态边框颜色
- 数据对象中的颜色（Timeline、Card 等）
- 传递给第三方库（X6、Plots）

### classNames 组合样式

```tsx
import classNames from 'classnames';
import styles from './Component.less';

<div className={classNames(styles.status, styles.success)}>成功</div>
<div className={classNames(styles.item, { [styles.active]: isActive })}>条件样式</div>
```

## ProComponents 规范

### ProForm

```tsx
const formRef = useRef<ProFormInstance>();

<ModalForm
  formRef={formRef}
  modalProps={{ destroyOnHidden: true }}  // 注意：不是 destroyOnClose
  onOpenChange={(open) => {
    if (!open) {
      formRef.current?.resetFields();
    }
  }}
>
  <ProFormText name="name" label="名称" />
</ModalForm>
```

**要点**：
- 使用 `formRef` 而非 `Form.useForm()`
- `destroyOnHidden: true`（不是 `destroyOnClose`）
- 关闭时重置：`formRef.current?.resetFields()`

### ProTable

```tsx
<ProTable<DataType>
  headerTitle="列表"
  actionRef={actionRef}
  rowKey="id"
  search={{ labelWidth: 120 }}
  scroll={{ x: 1400 }}
  options={{ reload: true, setting: true, density: true }}
  pagination={{
    defaultPageSize: 10,
    showQuickJumper: true,
    showSizeChanger: true,
    showTotal: (total) => `共 ${total} 条`,
  }}
  columns={columns}
  request={fetchData}
/>
```

#### 列配置 - 搜索控制

```tsx
// ✅ 正确：使用 search 属性
const columns = [
  { title: '名称', dataIndex: 'name' },  // 默认显示在搜索表单
  { title: '描述', dataIndex: 'desc', search: false },  // 隐藏搜索
  {
    title: '创建时间',
    dataIndex: 'createdAt',
    search: {  // 高级配置：自定义转换
      transform: (value) => ({ startTime: value?.[0], endTime: value?.[1] })
    }
  },
];

// ❌ 禁止：使用 hideInSearch（ProComponents 3.0 废弃）
{ title: '描述', dataIndex: 'desc', hideInSearch: true }
```

### 操作列

```tsx
{
  title: '操作',
  valueType: 'option',  // 必须
  width: 150,
  fixed: 'right',
  render: (_, record) => (
    <Space size="small">
      <Button type="link" size="small" icon={<EditOutlined />}>编辑</Button>
      <Popconfirm title="确认删除？" onConfirm={() => onDelete(record)}>
        <Button type="link" size="small" danger icon={<DeleteOutlined />}>删除</Button>
      </Popconfirm>
    </Space>
  ),
}
```

**按钮数量建议**：

| 数量 | 布局 |
|------|------|
| 1-3 个 | 直接平铺 |
| 4+ 个 | 常用平铺 + Dropdown 收纳 |

```tsx
// 4+ 个操作时
<Space size="small">
  <Button type="link" size="small">查看</Button>
  <Dropdown menu={{ items: moreItems }}>
    <Button type="link" size="small" icon={<MoreOutlined />}>更多</Button>
  </Dropdown>
</Space>
```

## 禁止使用的 API

### ProComponents（3.0 废弃）

| 组件 | 废弃用法 | 新用法 | 说明 |
|------|----------|--------|------|
| ProTable | `hideInSearch: true` | `search: false` | 列配置中控制搜索显示 |
| ProTable | `columnsStateMap` | `columnsState.value` | 列状态管理 |
| ProTable | `fixHeader` | `scroll: { y: number }` | 固定表头 |
| ProTable | `tip` | `tooltip` | 列提示 |
| ProCard | `ProCard.TabPane` | `tabs.items` | 页签配置 |
| ProLayout | `rightContentRender` | `actionsRender` + `avatarProps` | 右侧内容 |

```tsx
// ❌ 禁止
{ hideInSearch: true }
{ tip: '提示信息' }
<ProCard.TabPane tab="标签" key="1">内容</ProCard.TabPane>

// ✅ 使用
{ search: false }
{ tooltip: '提示信息' }
<ProCard tabs={{ items: [{ key: '1', label: '标签', children: '内容' }] }} />
```

## 静态方法 vs Hooks

### 消息提示

```tsx
// ✅ 推荐：useApp hook（v6 完全支持）
import { App } from 'antd';

const Component: React.FC = () => {
  const { message, modal, notification } = App.useApp();

  const handleClick = () => {
    message.success('操作成功');
    modal.confirm({ title: '确认？' });
  };
};

// ⚠️ 可用但需注意：静态方法
// v6 移除了兼容补丁，静态方法在 React 19 下直接可用
```

### 编码阶段

- [ ] 使用 Ant Design / ProComponents，无原生 HTML 控件

## FAQ

**Q: 什么时候可以用内联样式？**

仅用于动态计算的位置/尺寸属性：
```tsx
<div style={{ left: `${position}px`, width: `${width}px` }}>
```

**Q: CSS 变量 vs token？**

- Less/CSS 文件 → `var(--ant-color-text)`（无类型检查）
- TSX 文件 → `token.colorText`（有类型检查）

**Q: 表单再次打开残留数据？**

确保三点：
1. 使用 `formRef` 而非 `Form.useForm()`
2. 设置 `destroyOnHidden: true`
3. `onOpenChange` 中重置：`formRef.current?.resetFields()` → 清理 state

**Q: 修改后其他页面出问题？**

1. 立即 `git checkout` 回退
2. 不要用更多修改来"修复"
3. 改用 Less 类而非组件 props
